# Retrospectives

One file per game, `<repo>.md`, written when it ships, stalls or is shelved.
Under a page. Then move each lesson to its place in the skills (README: "Where a
lesson goes") and link the commit here.

```markdown
# <Game>: retrospective (<date>, <shipped / stalled / shelved>)

Shape and size: <A/B/C>, <lines>, <sessions>, <weeks>.

## What worked
- <one line each, with the evidence>

## What cost the most
| Cost | Cause | Caught by | Would have been caught by |
|---|---|---|---|
| <hours or sessions> | <the failure> | <playtester / test / review> | <the tool or rule> |

## What moved into the skills
- <lesson> -> <skill/file> (<commit>)

## What is still open
- <issue>
```
